# Test de déploiement Vue

Test de déploiement d'une application Vue 3 sur GitHub Pages.

## Fonctionnalités

- Script `deploy.sh` de publication sur GitHub Pages

## Technologies

Vue 3 · Vue Router · Vuex · GitHub Pages

## Lancer le projet

Prérequis : Node.js 16 ou plus.

```bash
git clone https://github.com/mafallseye/deploye.github.io.git
cd deploye.github.io
npm install
npm run serve
```
